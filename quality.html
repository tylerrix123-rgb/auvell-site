Paperwork for each lot

A certificate of analysis is the file that sits with a batch: what was tested, when, and by whom. This page is the library. Files go here only when a real report exists. We will not invent a lab or a purity number to fill the table.

01

Name

The compound on the file should match the vial label.

02

Lot

The lot code on the bottle and the file should be the same.

03

Date

When the test was finished, not when the page was designed.

04

Purity

A percentage only means something if the method is named on the file.
